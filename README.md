# 引元盒子 · 小元电视 Demo

在本目录运行 `python3 -m http.server 4173`，浏览器打开 `http://localhost:4173`。建议全屏，1920×1080 为 Figma 原始尺寸。

演示自动播放并循环，完整一轮约 58 秒。左上 World Model 常驻卡显示空间概况；旁边的动态卡在空气异常时出现，展示 CO₂ 读数、趋势及需要时的新风进度，空气回稳后淡出。右上设备回执共用一个位置：空间有人后显示用户将客厅主灯调至 60%，新风设备确认运行后显示空气置地机进入低噪模式；两卡分别停留约 3.6 秒，不会同时出现。右下“最近日志”打开小元行为时间轴，打开时收起设备回执并暂停故事，关闭后续播；可用左右方向键翻页、Esc 返回。日志含预置的昨日服务记录，当前空气事件按实际演示进度追加；用户自行调灯不入日志。点击 World Model 常驻卡或动态卡可查看当前依据，依据层打开时会暂停故事；左下空间、设备、记忆和电视入口目前只显示待接入提示；底部语音按钮模拟用户追问。遥控器键盘：方向上下在导航间移动、回车进入、Esc 返回；焦点在空白处时左右切换事件、空格暂停、R 重播、I 打开依据。

所有传感读数、设备动作、日志与天气均为 Mock。画面分别呈现控制请求、设备确认和环境改善；未接入真实设备或语音识别。


## 人物管理

首页右下“人物管理”提供四位虚构家人的照片、年龄与性别、当前活动及位置、声音样本、关联感知来源和最近活动。支持切换人物、播放／暂停声音、横向浏览感知来源、滚动历史、模拟语音回应与遥控器返回；添加人物和编辑入口打开小程序扫码引导，关闭后恢复焦点。进入时暂停首页故事，离开后按原状态续播。

照片和活动截屏为生成素材，声音为通用中文语音合成本地 WAV，活动与感知来源均为本地预置，不是真实家庭记录、人物识别、设备接入或跨端同步。爸爸的当前活动与原首页在场阶段关联，其余资料独立预置。GitHub 原版本尚无设备中心，人物页所列感知来源只读展示为在线 Mock；没有引入本地其他设备、空间或记忆功能。
